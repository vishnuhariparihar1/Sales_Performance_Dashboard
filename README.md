
# 📊 Sales Performance Dashboard – Excel

## 📌 Project Overview
This project focuses on analyzing sales performance using Microsoft Excel. The dashboard provides insights into sales executives' performance, regional sales, target achievement, and overall business performance.

It helps management monitor sales activities, compare actual sales with targets, and identify areas that require improvement.

## 🎯 Project Objectives
- Analyze sales performance across different regions.
- Track individual sales executives' performance.
- Compare actual sales with assigned targets.
- Identify target achievers and underperformers.
- Create an interactive and easy-to-understand dashboard.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts & Data Visualization
- Dashboard Design
